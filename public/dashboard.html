AE Title

Alat Worklist (modality)

Daftar alat/station yang bisa dipilih saat mengirim order. AE Title dipakai sebagai ScheduledStationAETitle di worklist, jadi pastikan sama dengan AET alat. Modality tiap alat otomatis muncul sebagai tab filter di panel Study & Gambar (mis. isi MG → muncul tab Mammografi (MG)). Isi IP alat + Port lalu tekan Daftarkan ke Orthanc supaya alat boleh menarik MWL dan mengirim gambar (C-STORE) tanpa mengedit konfigurasi Orthanc manual.
Nama alatAE TitleModalityIP / host alatPort

Tampilan & akses

Aktif (disarankan): alat baru yang mengirim gambar tanpa didaftarkan di daftar alat tetap punya tab sendiri (mis. MG). Nonaktif: tab hanya dari daftar alat di atas.
Bila Callback URL diisi, worker tools/notify-studies.php (cron tiap menit) mengirim POST event study.received ke URL tersebut saat study baru masuk, dengan header X-Bridge-Signature = sha256=HMAC(body, callback key).

Auto Expertise (Ollama)

Membuat draf bacaan (expertise) otomatis dari satu gambar study memakai model vision di server Ollama jaringan lokal — citra tidak dikirim ke internet. Hasil hanya draf; verifikasi dokter tetap wajib.

Pengguna dashboard (manager & operator)

Akun operator bisa membuat order worklist, melihat gambar, dan mengunduh ZIP/JPG, tetapi tidak bisa membuka Pengaturan, mengubah konfigurasi, atau mengelola user.
UsernamePeranPassword baru (opsional)

API Bridge — cara konek & kemampuan

Autentikasi program: header X-API-Key: <key> (isi field API Key di atas, lalu Simpan). Key hanya dikirim lewat header — bukan query string/cookie/body. Kolom X-API-Key di tabel bawah menandai endpoint yang boleh memakai key; sisanya butuh sesi login.
