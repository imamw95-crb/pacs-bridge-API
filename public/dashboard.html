API Bridge — cara konek & kemampuan

Autentikasi program: header X-API-Key: <key> (isi field API Key di atas, lalu Simpan). Key hanya dikirim lewat header — bukan query string/cookie/body. Kolom X-API-Key di tabel bawah menandai endpoint yang boleh memakai key; sisanya butuh sesi login.
Status API key: —
Daftar endpoint & contoh kode (curl / PHP / Python)
MethodPathFungsiX-API-Key
POST/loginlogin dashboard → cookie sesipublik
GET/mestatus sesi (via: session | api-key)publik
POST/logoutkeluarpublik
GET/healthstatus Orthanc + jumlah study/pasien✅
GET/accessionnomor accession baru (format alat Orthanc)✅
GET/worklistsdaftar order (worklist) yang ada di server✅
POST/worklistskirim order ke modalitas (nama, No. RM, accession, prosedur)✅
GET/PUT/DELETE/worklists/{id}lihat / ubah / hapus satu order✅
GET/studies?accession=cari study hasil foto by accession✅
GET/studies?name=cari study partial nama pasien (mis. adi watik)✅
GET/studies?patient_id=riwayat study pasien by No. RM✅
GET/studies/recent?date=today|all&limit=study terbaru (hari ini / semua tanggal)✅
GET/studies/{acc}/jpg?quality=gambar JPEG; tambah &watermark=1 untuk watermark (USG/EKG tanpa watermark)✅
GET/studies/{acc}/png?width=gambar PNG, bisa di-resize (thumbnail)✅
GET/studies/{acc}/zipunduh semua DICOM satu study✅
GET/studies/{acc}/zip-jpg?quality=ZIP berisi JPG ber-watermark, folder = No. RM (USG/EKG tanpa watermark)✅
GET/studies/{acc}/imagesdaftar gambar study (instance)✅
GET/instances/{id}/jpg?quality=1 gambar instance (JPEG)✅
GET/instances/{id}/fileunduh 1 file DICOM✅
GET/settingsbaca konfigurasi aktif (tanpa info API key)✅
GET/settings/api-keylihat API key utuh❌ manager
PUT/settingsubah konfigurasi❌ manager
POST/settings/passwordganti password akun sendiri❌ login
GET/POST/usersdaftar / tambah user dashboard❌ manager
PUT/DELETE/users/{username}ubah peran / reset password / hapus user❌ manager

Kolom X-API-Key: ✅ = boleh dipanggil program dengan header X-API-Key; ❌ = ditolak 403 bila memakai key — harus sesi login dashboard (manager). Tanpa key dan tanpa sesi selalu 401.

Kunci study {acc} boleh Accession Number, ID Orthanc (mis. 142ca2db-…), atau StudyInstanceUID — berguna untuk study yang dikirim alat tanpa accession (mis. workstation USG).
